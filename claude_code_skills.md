# Claude Code Skills: UI/UX Pro Max & Taste Skill

This file combines the core instructions, rules, and blueprints for the **UI/UX Pro Max** and **Taste Skill** instruction sets to optimize Claude Code for premium web design.

---

## 🎨 UI/UX Pro Max

### 🌟 Core Philosophy
Never generate generic "AI-slop" or unstyled boilerplate. Every user interface must look like it was designed by a world-class senior product designer and frontend engineer. Focus on strict mobile-responsiveness, high-fidelity aesthetic cohesion, and absolute pixel perfection.

### 📐 Layout & Structure Guidelines
1. **Visual Hierarchy:** Establish an immediate visual anchor on every page. Use deliberate contrast, scale, and positioning to direct the user's eye naturally.
2. **Spacing & Whitespace:** Implement generous whitespace. Never crowd text or functional components. Use strict multi-tiered layout systems (e.g., 4px/8px grids).
3. **Mobile-First Responsiveness:** Always design for mobile breakpoints first. Ensure interactive hit targets are large enough (minimum 44x44px) and adaptive layouts translate seamlessly to tablet and desktop monitors.

### 🎨 Color & Component Palettes
*   **Palette Consistency:** Choose a strict color harmony (e.g., Monochromatic, Analogous, Complementary) before outputting CSS/Tailwind classes. Restrict the palette to 1 primary tone, 1 secondary tone, and a curated set of neutral shades (light/dark variations).
*   **Accessible Contrast:** Ensure all text-to-background contrast ratios strictly meet WCAG AA standards (minimum 4.5:1 for normal text, 3:1 for large text).
*   **Interactive Micro-interactions:** Buttons, inputs, and anchors must feature subtle, fluid transitions (hover, active, focus states) using custom timing functions (`cubic-bezier`).

## 🧪 Taste Skill

### 🧠 Core Philosophy
Before writing a single line of layout code, analyze the character, tone, and deep stylistic footprint of the project. Break free from cookie-cutter designs by leaning heavily into distinct visual identities (e.g., Minimalist, Brutalist, Neo-brutalist, High-end Editorial, Cyberpunk).

### 📝 Strategic Intake Playbook
1. **Audience & Context Alignment:** Match the aesthetic layer to the domain. A financial tool requires clean trust anchors and precise metrics; a creative agency requires bold layout experimentation and striking typography.
2. **Mood Translation:** Map user intent to explicit "mood words" (e.g., *Sleek*, *Industrial*, *Cozy*, *Hyper-functional*). Let these words dictate the density of the grid, radius of the borders, and choices of accent variables.

### 🛠️ Execution Blueprint
*   **Stylistic Intentionality:** If going minimalist, remove all lines and rely solely on type scale and vast spacing. If going neo-brutalist, use hard black borders, high-contrast flat colors, and offset drop shadows.
*   **Typography Over Boilerplate:** Choose expressive font pairings. Use distinctive serifs for editorial weight or geometric monospaced fonts for clean engineering applications.
*   **Authentic Elements:** Avoid generic placeholder icons or unformatted boxes. Build beautifully designed custom indicators, loaders, and interface decorations that serve the overarching visual theme.
